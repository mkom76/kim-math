# Google Play Data safety 작성 초안

이 문서는 현재 소스 코드와 Play Console에 저장한 초안 기준의 기록입니다. 운영
방식이나 외부 서비스 사용이 바뀌면 Data safety도 함께 갱신해야 합니다.

## 기본 질문

- 앱이 사용자 데이터를 수집하거나 공유하는가: 예
- 전송 중 데이터 암호화: 예(운영 API는 HTTPS)
- 사용자가 데이터 삭제를 요청할 수 있는가: 예
- 삭제 요청 안내 URL: https://kim-math.site/privacy
- 앱 안에서 사용자가 계정을 생성하는가: 아니요. 계정은 소속 학원이 생성합니다.
- 앱 밖에서 생성한 계정으로 로그인하는가: 예(학원 관리자가 생성)
- 광고 포함: 아니요

  - 수집: 예(학년, 학교, 보호자, 소속 학원·반)

## 수집하지 않는 항목

- 위치
- 주소록
- 사진 및 동영상 파일
- 오디오 파일 또는 마이크
- 금융 정보
- 건강 및 피트니스 정보
- SMS 및 통화 기록

## 외부 처리 확인

- OpenAI
  - AI 피드백 생성 시 학생 이름, 시험·숙제 결과와 교사 피드백 일부가 전송될 수 있음
  - 개발자 지시에 따라 처리하는 서비스 제공자로 분류하여 `공유`에는 포함하지 않음
- Google Firebase Cloud Messaging
  - 1.0.0에서는 비활성화
  - 향후 푸시를 켜는 버전에서는 기기 토큰 처리 및 Data safety 갱신 필요
- YouTube
  - 앱 내 해설 영상 재생 시 개인정보 강화 모드 플레이어 사용
  - 재생 상호작용과 WebView 기기 무결성 증명 정보가 전송될 수 있음

## 대상 연령

실제 이용 학생의 연령대를 기준으로 선택해야 합니다. 만 13세 미만을 대상에
포함하면 Google Play Families 정책과 아동 개인정보 관련 추가 요건을 검토해야 합니다.
