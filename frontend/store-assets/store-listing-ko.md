# Google Play 스토어 등록 문안

## 앱 이름

킴매스 학생

## 짧은 설명

수업·시험·숙제·피드백을 한곳에서 확인하는 킴매스 학생용 학습 앱

## 자세한 설명

킴매스 학생은 학원 수업과 학습 기록을 학생이 쉽고 빠르게 확인할 수 있도록 만든
전용 앱입니다.

학생 ID와 PIN으로 로그인하면 오늘의 수업, 시험, 숙제, 클리닉 일정과 선생님의
피드백을 한곳에서 확인할 수 있습니다.

주요 기능:

- 수업 일정과 공지 확인
- 시험 응시와 결과·오답 확인
- 숙제 진행 상황과 보완할 문제 확인
- 수업별 선생님 피드백 확인
- 클리닉 일정과 최근 결과 확인
- 해설 영상 시청 및 학습 진도 기록
- 안전한 로그인 유지와 PIN 변경

이 앱은 킴매스에 등록된 학생을 위한 서비스입니다. 계정은 소속 학원에서 제공하며,
앱 안에서 새 계정을 만들 수 없습니다.

## 앱 액세스(심사자용)

앱의 전체 기능을 사용하려면 학생 로그인이 필요합니다.

- 학생 ID: 심사용 계정 생성 후 입력
- PIN: 심사용 계정 생성 후 입력
- 추가 안내: 학생 로그인 탭에서 위 ID와 4자리 PIN을 입력합니다.
